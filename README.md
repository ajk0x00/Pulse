# 💧 Pulse

**Pulse** is a lightweight **WearOS app** that helps you stay hydrated by vibrating in customizable rhythms at regular intervals. Unlike existing hydration reminder apps that are bloated, noisy, or intrusive, Pulse is **simple, clean, and focused** — no ads, no clutter, just gentle haptic nudges to remind you to drink water.

I built this app because I was frustrated by the trash solutions available on the market.  
This application is **vibe-coded**. ✨

---

## 🚀 Features
- ⌚ **WearOS native** – optimized for your smartwatch.
- 🔔 **Configurable reminders** – choose the interval that works for you.
- 🎵 **Custom vibration rhythms** – instantly recognizable haptic nudges.
- ⚡ **Battery-friendly** – runs quietly in the background without draining your watch.
- 🧘 **Minimal & distraction-free** – hydration reminders, nothing else.

## Development Setup

To build and run the app, you'll need Android Studio.

1.  Clone the repository: `git clone https://github.com/your-username/pulse.git`
2.  Open the project in Android Studio.
3.  Build and run the app on a WearOS emulator or a physical device.
